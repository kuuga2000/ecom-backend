# 4. Shipping address snapshot

This distinction is important.

The customer's saved address and the checkout shipping address should not be treated as the exact same persistent object.

A customer might select a saved address from the address book, but checkout should store a **snapshot/copy** of the relevant address values.

Conceptually:

```text
Customer
   |
   +-- Address Book
   |      |
   |      +-- Home
   |      +-- Office
   |
   +-- Active Cart
          |
          +-- Checkout State
                 |
                 +-- Shipping Address Snapshot
```

Do not simply store only:

```text
address_id = 123
```

as the checkout's shipping address.

The reason is that the customer may later edit or delete the saved address.

The checkout/order flow should preserve the values that were selected at the time.

The snapshot should contain fields such as:

- recipientName
- phone
- addressLine1
- addressLine2
- city
- province/state
- postalCode
- countryCode

It is acceptable to also retain the source customer address ID for reference, but the snapshot values must stand independently.

This architecture will also prepare the project for Milestone 7, where the order must retain an immutable shipping-address snapshot.
